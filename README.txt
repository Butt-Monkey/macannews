87 · Macan News — файлы для хостинга
====================================

Содержимое:
  index.html          — сам сайт (вёрстка + стили + скрипты)
  87craft/index.html  — страница Minecraft-сервера 87CRAFT
  87craft/mods/       — сборка модов 87CRAFT: ZIP (папка mods + инструкция) и .mrpack
                        (источник и проверка — папка «моды-сборка» в стенде)
  404.html            — фирменная страница «не найдено» (старые ссылки на
                        посты /n/<номер>/ она отправляет в ленту сайта)
  sw.js               — Service Worker: офлайн + мгновенные повторные визиты
  favicon.ico         — иконка в корне (нужна поисковикам, Яндексу особенно)
  assets/             — медиа: фото, аудио, видео, иконки
  assets/games-40.js  — код игр (змейка, пинг-понг): грузится только при
                        входе в раздел «Игры»
  assets/fonts/       — шрифты самохостом: Schibsted Grotesk (латиница/цифры)
                        + minecraft.ttf. Кириллица — системный шрифт.
  assets/og-87.png    — картинка превью ссылки в TG/соцсетях (1200×630)
  site.webmanifest    — манифест PWA (иконка и ярлыки NEWS / 87CRAFT)
  robots.txt, sitemap.xml — для поисковиков

Домен: macannews.ru (GitHub Pages, репозиторий Butt-Monkey/macannews, ветка main).

ВАЖНО при заливке на GitHub:
  news.json, папки .github/, assets/news/ и n/, файл sitemap-news.xml трогать
  НЕ нужно — их наполняет бот, который тянет посты из Telegram-канала. В этом
  архиве их намеренно нет, чтобы заливка не перезаписала свежую ленту.

После обновления файлов подними VERSION в sw.js (иначе у посетителей
останется старая версия в кэше) и обнови страницу через Ctrl+Shift+R.
