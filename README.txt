87 · Macan News — файлы для хостинга
====================================

Содержимое:
  index.html          — сам сайт (один файл: вёрстка + стили + скрипты)
  404.html            — фирменная страница «не найдено»
  sw.js               — Service Worker: офлайн + мгновенные повторные визиты
  favicon.ico         — иконка в корне (нужна поисковикам, Яндексу особенно)
  assets/             — медиа: фото, аудио, видео, иконки
  assets/fonts/       — шрифты самохостом: Schibsted Grotesk (латиница/цифры,
                        woff2) + minecraft.ttf (только раздел 87CRAFT).
                        Кириллица — системный шрифт, внешних запросов нет.
  assets/og-cover.jpg — баннер для шаринга в TG/соцсетях (1200×630)
  site.webmanifest    — манифест PWA (иконка на телефоне)
  robots.txt          — для поисковиков
  sitemap.xml         — карта сайта

Домен: macannews.ru (GitHub Pages, репозиторий Butt-Monkey/macannews, ветка main).
При смене адреса сделай поиск-замену 'macannews.ru' в index.html, robots.txt,
sitemap.xml.

ВАЖНО при заливке на GitHub:
  news.json, папку .github/ и assets/news/ трогать НЕ нужно — их наполняет
  бот, который тянет посты из Telegram-канала. В этом архиве их намеренно нет,
  чтобы заливка не перезаписала свежую ленту.

После обновления файлов подними VERSION в sw.js (иначе у посетителей
останется старая версия в кэше) и обнови страницу через Ctrl+Shift+R.
